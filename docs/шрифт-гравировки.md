# Шрифт гравировки: что выяснено

Заказчик требует **Segoe Print, сжатый по горизонтали на 50 %**.
Сжатие сделано ровно так. С самим шрифтом сложнее.

## Можно ли ставить Segoe Print на сайт

Да — и без лицензии, если не раздавать файл.

**Что запрещено.** Лицензия Microsoft запрещает *раздачу файла* шрифта:
копировать на чужие машины, вкладывать в приложения, выкладывать
на сервер и подключать через `@font-face`. В последнем случае файл
скачивает браузер каждого посетителя — это и есть раздача.

**Что разрешено и что мы делаем.** В `font-family` шрифт только
называется по имени. Файл не передаётся: браузер берёт тот, что уже
стоит у посетителя. На Windows Segoe Print идёт из коробки, поэтому
там превью показывает настоящую гравировку — законно и бесплатно.

Стопка такая: `"Segoe Print", Neucha, cursive`. Кто открыл сайт
с Windows — видит оригинал. Кто с телефона или макбука — замену.

**Когда лицензия всё-таки нужна.** Только если нужно, чтобы настоящий
Segoe Print видели *все*, включая телефоны. Тогда покупается веб-лицензия
у Monotype (Segoe Print продаётся на MyFonts: настольная от 39 $
за начертание, 49 $ за оба; веб-лицензия считается по просмотрам
страниц). Учитывая, что заходов с телефонов у такого сайта большинство,
покупка имеет смысл — но она не обязательна.

## Замена для тех, у кого Segoe Print нет

Сравнил кандидатов с настоящей гравировкой на фотографии партии
(`assets/image 17.png`, надпись «Чиганашина / Арина / 2022»).

| Шрифт | Кириллица | Начертание | Вывод |
|---|---|---|---|
| **Neucha** | да | прямой печатный, буквы не связаны | **ближе всех по рисунку** |
| Pangolin | да | прямой, но круглее и ровнее | годится, дальше от оригинала |
| Caveat | да | наклонный, полусвязный | стоял раньше, заметно курсивнее |
| Marck Script, Bad Script | да | связный курсив | не тот класс |
| Amatic SC | да | узкий, декоративный | не тот класс |

Взята **Neucha**. У неё один вес против Bold у оригинала, поэтому
в разметке стоит `font-weight: 700`: на Windows возьмётся настоящее
жирное начертание, у замены браузер утолщит сам. Ручную обводку сняли —
на Windows она давала бы двойную жирность.

## Как поменять на настоящий

Если купите веб-лицензию — положить файлы в проект, объявить `@font-face`
и оставить то же имя первым в стопке. Размеры, сжатие и центровка
считаются от чертежа и не изменятся.
