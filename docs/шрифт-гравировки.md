# Шрифт гравировки: что выяснено

Заказчик требует **Segoe Print, сжатый по горизонтали на 50 %**.
Сжатие сделано ровно так. С самим шрифтом сложнее.

## Можно ли ставить Segoe Print на сайт

**Тот, что стоит в Windows, — нельзя.** Segoe Print поставляется
с Windows и Office. Лицензия Microsoft разрешает печатать и продавать
напечатанное, но **запрещает раздавать сам файл шрифта** — копировать
на другие компьютеры, вкладывать в приложения и подключать на сайте
через `@font-face`. Веб-шрифт — это именно раздача файла: браузер
каждого посетителя скачивает его себе.

**Отдельную веб-лицензию купить можно.** Segoe Print продаётся
на MyFonts (площадка принадлежит Monotype, правообладателю знака
Segoe Print). Настольная лицензия — от 39 $ за начертание, 49 $
за оба. Веб-лицензия покупается отдельно и считается по числу
просмотров страниц в месяц.

**Вывод:** запрета нет, есть цена. Для сайта такого размера это
разовая покупка, а не абонемент.

## Пока лицензии нет — замена

Сравнил кандидатов с настоящей гравировкой на фотографии партии
(`assets/image 17.png`, надпись «Чиганашина / Арина / 2022»).

| Шрифт | Кириллица | Начертание | Вывод |
|---|---|---|---|
| **Neucha** | да | прямой печатный, буквы не связаны | **ближе всех по рисунку** |
| Pangolin | да | прямой, но круглее и ровнее | годится, дальше от оригинала |
| Caveat | да | наклонный, полусвязный | стоял раньше, заметно курсивнее |
| Marck Script, Bad Script | да | связный курсив | не тот класс |
| Amatic SC | да | узкий, декоративный | не тот класс |

Взята **Neucha**. У неё один вес против Bold у оригинала, поэтому
гравировке добран вес обводкой в 5 % кегля: лазер на металле оставляет
сплошной след, тонкий штрих на товар не похож.

## Как поменять на настоящий

Когда купите лицензию — положить файлы в проект и заменить одну строку
в `lib/site.ts`: `css: "var(--font-neucha)"` на своё семейство. Размеры,
сжатие и центровка считаются от чертежа и не изменятся.
