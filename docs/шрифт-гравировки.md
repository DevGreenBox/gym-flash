# Шрифт гравировки: что выяснено

Заказчик требует **Segoe Print, сжатый по горизонтали на 50 %**.
Сжатие сделано ровно так. С самим шрифтом сложнее.

**Решение от 27.08: на сайте стоит Playpen Sans 700, Segoe Print убран
из стопки совсем.** Причина не только лицензионная — см. «Почему убрали
Segoe совсем» ниже. В цехе при гравировке оригинал никуда не делся.

## Можно ли ставить Segoe Print на сайт

Перепроверено по первоисточнику 27.08 — [Font redistribution FAQ,
Microsoft Learn](https://learn.microsoft.com/en-us/typography/fonts/font-faq),
раздел **Web**. Ответ не изменился, но теперь он дословный.

**Называть в стопке — можно, и лицензия не нужна вообще.** Дословно:

> Web content publishers are free to specify Windows supplied fonts in their
> font stacks. In fact, as a web page creator you don't even need to be a
> Windows licensee to include a Windows font name in a CSS font stack, as the
> "use" of the font occurs on the Windows device, not on your web server.

Это ровно то, что стоит сейчас: `"Segoe Print", Neucha, cursive`. На Windows
рисуется настоящий Segoe Print Bold, бесплатно и законно.

**Класть файл на сервер — нельзя.** Дословно:

> Web fonts are fonts that are hosted on a web server. You do not have rights to:
> - copy fonts from a Windows installation to a web server, a process known as
>   web font "self-hosting".
> - convert the font to the formats typically associated with web fonts, such
>   as the WOFF or WOFF2 format.

Запрещены оба действия по отдельности: и копирование файла на сервер,
и перегон в WOFF/WOFF2. Это единственный способ показать шрифт на телефоне,
поэтому на телефоне его без лицензии не будет.

**Исключения «для демонстрации» нет.** Единственное послабление — document
embedding, и оно про файлы документов: Word, PowerPoint, PDF, ePub. Про
приложения и устройства сказано отдельно и прямо:

> Can I embed the fonts into a game, application or device I'm developing based
> on the document font embedding permissions? **No**, document font embedding
> permissions relate to embedding fonts in documents only, not embedding fonts
> in games, apps and devices.

**А вот картинки — можно, и это важно.** Отрисованный текст в виде
изображения Microsoft приравнивает к печати:

> Can I make graphic files using the fonts, say a screengrab, advertisement,
> meme or poster and share, sell or redistribute those graphic files?
> We view creating graphic files as being essentially the same as printing
> from an output device.

> The graphic file must be an image of a word, phrase or passage of text.
> Converting the font to a bitmap font (where each letter is treated
> individually) is not allowed.

Значит любая **готовая картинка** с настоящим Segoe Print — примеры работ,
галерея, баннеры, обложки — показывается всем, включая телефоны. Делать её
надо на машине с установленным шрифтом, целой фразой, а не поглифовым
атласом.

**Отрисовка на нашем сервере не проходит.** Мысль «шрифт лежит у нас,
посетителю уходит картинка» разбивается о ту же строчку: копировать файл
на сервер прав нет. Linux-функция на Vercel — не лицензированная Windows.

**Итого.** Живое превью в конструкторе на телефоне — только через
веб-лицензию. На MyFonts: Segoe Print Std Bold есть, настольная $39
за начертание, $49 за оба, веб-лицензия годовая и считается отдельно.

## Почему убрали Segoe совсем, а не оставили первым в стопке

Он есть только на Windows. Пока он стоял первым, одна и та же флешка
выглядела по-разному: заказчик со своего ПК видел одно, покупательница
с телефона — другое. Конструктор показывает человеку его будущую
покупку, и она не должна зависеть от того, с чего он зашёл.

Ради одного корректного превью у нас на Windows это того не стоило.

## Как выбирали замену

Выгружен каталог Google Fonts целиком (`fonts.google.com/metadata/fonts`).
Рукописных гарнитур с кириллицей там **пятнадцать**, и почти у всех
один вес — то есть настоящего Bold нет. С кириллицей и живым жирным
остаётся три: Playpen Sans, Shantell Sans, Balsamiq Sans.

Все отрисованы на той же пластине рядом с фотографией партии
(`assets/image 17.png`, «Чиганашина / Арина / 2022»).

| Шрифт | Веса | Вывод |
|---|---|---|
| **Playpen Sans** | 100–800 | **взят**: прямой, не связан, той же ширины; цифры почти один в один |
| Shantell Sans | 300–800 | маркернее и шире, дальше от фотографии |
| Balsamiq Sans | 400, 700 | ближе к Comic Sans, рукописного мало |
| Neucha | 400 | скелет близкий, но веса нет — на пластине жиже гравировки |
| Pangolin | 400 | круглее и шире, веса нет |
| Caveat | 400–700 | наклонный, полусвязный — другой класс |

Playpen Sans — SIL Open Font License, отдаётся с нашего сервера через
`next/font`, поэтому одинаков на Windows, iOS, Android и macOS. Вес
пришпилен к 700: гарнитура переменная, но нужен один вес, и статический
экземпляр весит меньше.

Кириллица проверена целиком: 33 буквы в обоих регистрах, «Ё», цифры,
«№», кавычки-ёлочки, тире. «5 «Б»» и «г. Ростов-на-Дону» набираются
без подстановок.

## Вес 400, а не 700

Чертёж требует жирное начертание, но у Playpen Sans штрих сам по себе
толще, чем у Segoe Print: 700, 600 и 500 на пластине выходили плотнее
гравировки. Гарнитура переменная, поэтому ступень подобрана сверкой
с фотографией партии, а не взята из чертежа.

## Проверка вместимости

Замерено на худших случаях уже без постоянного сжатия
(`SQUEEZE = 1`, см. [чертёж-флешки.md](чертёж-флешки.md)).
Зона надписи 5,40 … 34,50 мм, Зона 2 — 36,00 … 47,50 мм.

| Что | Занял, мм |
|---|---|
| Строка из 19 широких букв «ЩЖШЮЫЪЭ…» | 5,41 … 34,49 |
| «г. Ростов-на-Дону» | 12,51 … 27,39 |
| Подпись «Скакалка» | 36,48 … 47,15 |
| Подпись «Булавы» | 37,00 … 46,59 |

Ничего не выходит ни на колпачок, ни за поле гравировки. Длинная
строка дожимается ровно до границы зоны, кегль при этом не меняется.

Для сверки: «Чиганашина» без сжатия занимает 28,05 мм, на готовой
флешке — 25,1 мм.

## Если понадобится вернуть Segoe

Купить веб-лицензию, положить файлы в проект, объявить `@font-face`
и поставить имя первым в стопке. Размеры, сжатие и центровка считаются
от чертежа и не изменятся.
