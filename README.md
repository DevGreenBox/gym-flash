# Personal Flash

Сайт именных флешек с гравировкой: Ростов-на-Дону, ИП Андеев В. А.
Десять разделов из макета заказчика, конструктор гравировки, корзина и заявка.
Сервера нет: корзина и собранные в конструкторе флешки лежат в `localStorage`
этого браузера, формы замоканы, фотографий разделов пока нет — вместо них
серые экраны.

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm build
pnpm lint
```

- Бриф заказчика — [CLAUDE.md](CLAUDE.md)
- Правила работы — [AGENTS.md](AGENTS.md)
- Дизайн-система — [docs/design-system.md](docs/design-system.md)

## Что нужно от заказчика

- фотографии: комплект, гравировка крупным планом, примеры работ,
  рекомендательные письма (фон героя уже есть);
- тексты разделов «Для учёбы», «Памятный подарок», «Отзывы», «Примеры работ»;
- цены, минимальный заказ, объём памяти, срок изготовления;
- точные цвета анодирования (сейчас сняты глазом с фотографии);
- ссылки на WhatsApp и Telegram;
- **вес одной флешки с подвеской и вес упаковки** — без них не считается
  ни доставка, ни накладная (`lib/delivery.ts`);
- **договор и ключ API СДЭК** — для виджета пунктов выдачи, тарифов
  и транспортной накладной;
- почтовый ящик, куда уходят заявки;
- логотип в векторе и файл знака с чёрной флешки («Для тренировок»);
- веб-лицензия на Segoe Print, если нужен точный шрифт гравировки.
